# 水果忍者 · 再来一刀

一个可以直接离线玩的 HTML5 切水果游戏。原生 Canvas + Web Audio，零第三方运行依赖，支持鼠标与触屏。

**[在线试玩](https://fruit-ninja-dojo-20260905.yongqixue666.chatgpt.site/)**

## 这一版有什么

- 六种水果按品种保持统一尺寸，带高光、果皮纹理与新鲜切面。
- 120 Hz 固定步长物理与渲染插值；关卡计时独立于帧率和视觉慢动作。
- 高速连续手势采样，弧线挥刀也能准确命中；刀光有三种配色。
- 按刀的方向与速度飞散的果肉、果汁和火花，连击音效、短暂慢动作与轻微震动。
- 经典模式在水果即将掉落时预警，漏果时发出双音报警并显示剩余机会。
- 可调音量、画面效果和震动；支持系统“减少动态效果”偏好。
- 音效缓冲与水果阴影预先缓存，木纹背景独立绘制，减少游戏过程中的重复工作。
- 最高分与设置保存在当前浏览器，旧版最高分可以继续使用。

## 玩法

| 模式 | 规则 |
| --- | --- |
| 经典 | 漏果 3 次或切到炸弹，本局结束。 |
| 街机 | 60 秒冲刺；炸弹扣 10 分；每切开 20 个水果触发 6 秒双倍得分。 |
| 禅 | 90 秒，无炸弹，无漏果惩罚。 |

按住鼠标左键拖动，或滑动手指切水果。同一刀连续命中 3 个以上水果获得连击奖励；命中间隔不超过 0.34 秒。空格暂停/继续，Esc 暂停或关闭弹窗，M 切换音效。切换窗口时自动暂停。

## 本地运行

直接用现代浏览器打开根目录的 `index.html` 即可离线玩。

开发与测试需要 Node.js 18 或更高版本，无需安装依赖：

```sh
npm run dev
npm test
npm run build
```

开发地址是 `http://127.0.0.1:4174`。修改 `src/` 后重新执行构建，再刷新浏览器。

## 目录

```text
src/index.html     页面模板
src/styles.css     界面与响应式样式
src/game.js        绘制、物理、手势、计分与音效
tests/            确定性游戏回归测试，无需浏览器依赖
scripts/serve.cjs  本地静态服务器
build.cjs         打包为可离线运行的单文件 HTML
index.html        完整单文件游戏
out/index.html    静态部署输出（构建生成）
```

部署时使用 `out/` 中的静态文件即可，不需要数据库、服务器端密钥或 AI API。最高分与偏好仅属于每位访问者自己的浏览器。移动端振动取决于设备和浏览器支持情况。
